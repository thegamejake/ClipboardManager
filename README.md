# 剪貼簿管理器（Clipboard Manager）

一個輕量級的 Chrome 擴充功能，會自動儲存最近 10 次複製（Ctrl+C）的內容，方便快速存取歷史紀錄。

## 功能特色

✨ **核心功能**
- 自動監聽 Ctrl+C 事件，儲存複製內容
- 最多儲存 10 筆歷史紀錄
- 彈出視窗顯示所有歷史項目與預覽文字
- 一鍵將任一歷史項目複製回剪貼簿
- 快速刪除單筆紀錄
- 批次清空所有歷史紀錄

📝 **使用者體驗**
- 顯示每筆紀錄的簡短預覽（最多 50 個字元）
- 相對時間顯示（「剛剛」、「5 分鐘前」等）
- 清新簡約的淺色主題設計
- 本機儲存，隱私安全

## 安裝方式

### 本機開發安裝

1. **開啟 Chrome 擴充功能管理頁面**
   - 輸入 `chrome://extensions/`，或在選單中選擇「更多工具」→「擴充功能」

2. **啟用開發人員模式**
   - 切換右上角的「開發人員模式」開關

3. **載入未封裝項目**
   - 點選「載入未封裝項目」
   - 選擇本專案資料夾

4. **開始使用**
   - 在網頁上複製內容（Ctrl+C）
   - 點選瀏覽器右上角的擴充功能圖示查看歷史紀錄

## 使用方式

### 基本操作

| 操作 | 說明 |
|------|------|
| **Ctrl+C** | 在任何網頁複製內容時自動儲存到歷史 |
| **點選圖示** | 開啟歷史紀錄彈出視窗 |
| **複製** | 將選取的歷史項目複製到剪貼簿 |
| **刪除** | 刪除單筆歷史紀錄 |
| **清空** | 清空所有歷史紀錄（需確認） |

### 範例情境

**情境 1：重複使用程式碼片段**
```
1. 在 Stack Overflow 複製程式碼片段
2. 在編輯器貼上使用
3. 之後需要相同程式碼時，點選擴充功能 → 點選歷史項目 → 複製
```

**情境 2：暫存多個連結**
```
1. 複製第一個連結（自動儲存）
2. 複製第二個連結（自動儲存）
3. 複製第三個連結（自動儲存）
4. 之後可直接從歷史紀錄中選擇任一連結使用
```

## 技術架構

### 核心原理

- **Content Script** 在網頁載入時注入，使用 `document.addEventListener('copy')` 監聽複製事件
- 複製觸發時透過選取文字或 `navigator.clipboard.readText()` 讀取實際剪貼簿內容
- 透過 `chrome.runtime.sendMessage()` 傳送給 Background Script
- **Background Script** 將資料儲存至 `chrome.storage.local`，最多保留 10 筆
- **Popup** 從 Background 讀取歷史，提供刪除、複製等互動

### 儲存結構

```javascript
chrome.storage.local['clipboardHistory'] = [
  {
    text: "複製的文字內容",
    timestamp: 1621234567890
  },
  // ... 最多 9 筆較早的紀錄
]
```

## 權限說明

| 權限 | 用途 | 必要性 |
|------|------|--------|
| `clipboardRead` | 讀取使用者複製的內容 | ✅ 必要 |
| `clipboardWrite` | 允許從歷史複製回剪貼簿 | ✅ 必要 |
| `<all_urls>` | 在所有網站注入監聽腳本 | ✅ 必要 |

## 注意事項

⚠️ **重要提示**
- 歷史紀錄儲存在瀏覽器本機，清除瀏覽器資料會一併清空紀錄
- 僅支援文字複製，不支援圖片／檔案複製
- 部分特殊網站（Chrome 系統頁面、部分受限制網站）無法運作
- 歷史紀錄上限為 10 筆，新增內容會自動刪除最舊的項目

## 疑難排解

### 問題：複製後沒有儲存

**原因：** 部分特殊網站禁止 Content Script 執行  
**解決：** 檢查 Chrome 開發人員工具主控台是否有錯誤訊息

### 問題：歷史紀錄不顯示

**原因：** popup 與 background 通訊異常  
**解決：**
1. 重新載入擴充功能（在擴充功能管理頁面點選重新整理）
2. 檢查開發人員工具（F12）中的錯誤

### 問題：複製速度較慢

**原因：** 儲存空間操作可能阻塞主執行緒  
**解決：** 這是瀏覽器限制，一般情況可忽略
